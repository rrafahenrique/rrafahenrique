Tenho interesse em utilizar dados e métodos estatísticos para compreender problemas, identificar padrões e gerar insights que auxiliem na tomada de decisões. Ao longo da minha jornada, desenvolvi projetos envolvendo **análise exploratória de dados**, **modelagem preditiva**, **segmentação de clientes**, **detecção de anomalias** e **experimentação estatística**.
